# Life Compass contributor guide

- The project identity is `life-compass`. The `undo418` Manus Training Compass is
  legacy reference material, not the current repository.
- Before writing Expo code, read the exact SDK 57 documentation at
  https://docs.expo.dev/versions/v57.0.0/.
- The canonical source is this repository's `main` branch. Keep changes
  reproducible from a clean clone and verify them with the commands in
  `README.md`.
- Do not copy AI Memory, private notes, local machine paths, health/device data,
  local databases, backups, credentials, cookies, or populated environment
  files into this repository or into public issues/reviews.
- Health integrations remain read-only, camera preview remains no-save, and
  product claims must not expand into diagnosis, treatment, or guarantees.
